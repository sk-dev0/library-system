# 図書館管理システム

Java Swing による GUI を用いた図書館管理システムである。大学の講義で制作した。

書籍・会員・ジャンル・貸出の 4 つのデータを管理し、貸出と返却の操作を行うことができる。データは TSV ファイルに保存される。

## 主な機能

- 書籍・会員・ジャンルの追加、編集、削除
- 書籍・会員・貸出の検索
  - 書籍：タイトル、著者の部分一致検索、ジャンルによる絞り込み
  - 貸出：書籍タイトル、会員名の部分一致検索、未返却のみの表示
- 貸出と返却
  - 貸出ダイアログ内で書籍と会員を検索し、ダブルクリックで入力欄に自動入力
  - 在庫がない書籍は貸出不可
  - 返却済みの貸出は再返却不可
- 入力バリデーション
- 削除時の整合性チェック
- TSV ファイルによるデータの永続化
- ID の表示用整形

## 動作環境

- Java 11 以上（OpenJDK 26 で動作確認）

## コンパイルと実行

プロジェクトのルートディレクトリで以下を実行する。

```
javac -d bin -sourcepath src src/library/Main.java
java -cp bin library.Main
```

データは `data` ディレクトリから相対パスで読み込むため、必ずプロジェクトのルートディレクトリで実行する必要がある。

```
        │   LoanRepository.java
        │   MemberRepository.java
        │
        ├─service
        │   LibraryService.java

        │  │  MainFrame.java
        │  │

        │  │   BookEditDialog.java
        │  │   GenreEditDialog.java
        │  │   LoanEditDialog.java
        │  │   MemberEditDialog.java
        │  │

        │      BookPanel.java
        │      GenrePanel.java
        │      LoanPanel.java
        │      MemberPanel.java
        │
        └─util
            IdFormatter.java
            TsvIO.java
```

責務ごとに以下の層に分けている。

| 層 | 役割 |
| --- | --- |
| model | データの構造を定義するクラス群 |
| repository | データをメモリ上で保持し、TSV ファイルに読み書きする |
| service | 複数のリポジトリをまたぐ業務ロジック（貸出、返却、削除時の整合性チェック、検索など） |
| ui | 画面表示とユーザー操作 |
| util | 複数の層から使われる共通処理 |

`Main.java` で各層の初期化と依存関係の組み立てを行っている。

## 設計判断

### データモデル

- 貸出は書籍と会員の多対多の関係になるため、会員に貸出情報を持たせず、中間表として貸出表を独立させた。
- 貸出中の冊数や貸出可能かどうかは、貸出表の未返却の記録から求められるため、書籍には持たせていない。
- ジャンルは独立した表として切り出した。ジャンルを変更する際に 1 か所の編集で済み、入力時の表記揺れも防げる。
- 返却期限とペナルティは扱わないため、返却期限は設けていない。

### ID

- ID は内部では整数で管理し、表示時に接頭辞を付けて整形している。
  - 書籍：ジャンルの接頭辞（大文字 2 文字）＋ 4 桁
  - 会員：`M` ＋ 4 桁
  - 貸出：`L` ＋ 4 桁
  - ジャンル：数値のまま
- 書籍 ID はジャンルの接頭辞が違っても通し番号にしている。ジャンルごとに番号を振ると、接頭辞を除いた数値が重複し、ID による検索で問題が生じるためである。

### データの保存

- 実行のたびにデータがリセットされないよう、TSV ファイルとして切り出した。起動時に読み込み、ウィンドウを閉じるときに書き出す。
- 形式を TSV にしたのは、タイトルや著者名にカンマや空白が入ることはあっても、タブが入る可能性は低いと考えたためである。

### 貸出操作

- 当初は書籍 ID・タイトル・会員 ID・名前を手入力する方式であったが、入力ミスや、書籍が劣化して情報が読めない状況も考え、貸出ダイアログの半分を書籍と会員の参照用タブとし、検索とダブルクリックで入力できるようにした。

### バリデーションと削除の制限

- ユーザーが想定外の操作をしても不正なデータが登録されないよう、入力や削除の各所でチェックを行っている。
- 貸出表は記録であるため、編集と削除はできないようにしている。
- 書籍や会員を削除すると、それを参照する貸出記録が残るため、cascade 削除は採用せず、以下の場合は削除できないようにした。
  - 現在貸出中の書籍・会員
  - 貸出記録が 1 件でもある書籍・会員
- 書籍に使われているジャンルは削除できない。

## 初期データについて

`data` ディレクトリの TSV ファイルに含まれる書籍・会員などのデータは、すべて架空のものである。
